# Python Phone System Simulation

A menu-driven phone simulation built with Python to practise object-oriented programming and core Python concepts.

## Features

- Phone lock/unlock and brightness control
- Mobile data, camera, and messaging simulation
- Contact calling and gallery access
- JSON file handling and exception handling

## Technologies

Python, JSON, OOP

## How to Run

```bash
python3 phone.py
```

*Note: This is a console-based simulation for learning purposes.*
